# 🎓 AI-Powered Online Attendance Management System

An AI-powered attendance management system that automates student attendance using **Face Recognition and Computer Vision**.

## 🚀 Features

- 🤖 AI-based face recognition
- 📸 Automatic attendance marking
- 👨‍🎓 Student registration
- 📊 Attendance records
- 🕒 Date and time tracking
- 🖥️ Easy-to-use dashboard

## 🛠️ Tech Stack

- Python
- OpenCV
- Face Recognition
- NumPy
- Pandas
- Streamlit
- SQLite

## ⚙️ How It Works

1. Register student details and face.
2. Capture the student's face using the camera.
3. Recognize the student using AI.
4. Automatically mark attendance.
5. Store attendance records in the database.

## 🎯 Problem Solved

The system reduces manual attendance work and makes attendance management faster, easier, and more efficient.
